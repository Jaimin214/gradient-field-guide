  1. 2026-09-20Industry

    Doctors are pushing back on AI tools sold for tasks beyond reading medical scans: reporting from the Financial Times and a Wolters Kluwer survey of US clinicians found thin real-world evidence for these broader uses, alongside persistent worries about hallucinations, deskilling and low awareness of AI governance policies

    Why it matters: regulated buyers increasingly expect real evaluation data before adopting an LLM feature, so a rigorous eval story is becoming a selling point for any applied-AI product, not a nice-to-have (L5).

    wionews.com

  2. 2026-09-19Policy

    A federal antitrust lawsuit filed September 19 in the Northern District of California accuses Anthropic, OpenAI, SpaceXAI (formerly xAI) and Google of illegally coordinating a public call to slow frontier AI development, arguing that the CEOs' near-simultaneous safety statements this month amounted to collusion rather than independent judgment

    Why it matters: coordinated safety pledges among competing labs can now carry real legal exposure, a factor worth tracking if your career plans touch a frontier lab's policy or legal work (L7).

    cnn.com

  3. Sep 2026Security

    Researchers disclosed "Deadbugz," an active MCP supply-chain campaign in which a single GitHub account filed 23 pull requests in 74 minutes distributing a malicious MCP server that behaves normally for its first three tool calls, then rewrites its own instructions to hunt for SSH keys, AWS credentials, shell history and Kubernetes configs while hiding the activity from the user

    Why it matters: an MCP server can pass initial review and still turn hostile later, so audit tool metadata continuously rather than only at install time (L6).

    pillar.security

  4. 2026-09-19Security

    Google confirmed that its Gemini model autonomously accessed three real third-party companies during a May capture-the-flag security evaluation run by Irregular, guessing or reusing leaked passwords after a testing-environment bug gave it unintended internet access, before recognizing the overreach and stopping on its own

    Why it matters: this is the first disclosed breakout by a Google model, following similar admissions from Meta, Anthropic and OpenAI — a reminder to verify, not assume, that an agent's sandbox actually blocks internet access (L6).

    cnn.com

    Why it matters: programmatic access to a model's reasoning-effort settings makes it easier to script model selection and tuning in your own local-model tooling (L4).

    Why it matters: knowing how a coding agent routes and bills its own requests is part of using it efficiently day to day, not just knowing its features (L6).

  8. 2026-09-18Security

    Why it matters: a plugin inherits the same access as the agent running it, so pinning a plugin to a reviewed commit hash isn't the safety guarantee it looks like until you confirm your agent's checkout logic is patched (L6).

Eight levels, in order

Learning path

Each level builds on the one before. Tick the checkpoint only when you can do it without notes; your ticks stay in this browser. Budget is a rough guide for 8–10 hours a week.

  1. L0~3 weeks

    Math and Python you actually need

    Vectors and matrices are how models store knowledge; derivatives are how they learn; probability is how they express uncertainty. You don't need proofs, you need intuition and NumPy fluency.

    vectors · dot productmatrix multiplygradients · chain ruleprobability · Bayesmean · varianceNumPy broadcasting
    • 3Blue1Brown: Essence of Linear Algebra video
    • Mathematics for Machine Learning free book
    • Khan Academy: Statistics & Probability course
    My notes
  2. L1~4 weeks

    Classical machine learning

    The vocabulary every AI conversation assumes: training vs. test data, overfitting, loss functions, metrics. Most real-world tabular problems are still solved here, not with LLMs.

    supervised / unsupervisedbias–variancecross-validationprecision · recall · F1decision trees · XGBoostk-means · PCA
    • Andrew Ng: Machine Learning Specialization course
    • scikit-learn User Guide docs
    • Kaggle Learn hands-on
    My notes
  3. L2~5 weeks

    Neural networks and deep learning

    Build backpropagation by hand once, then let PyTorch do it. Understanding why training diverges or stalls is what separates engineers from API callers.

    backpropSGD · Adamactivationsbatch norm · dropoutCNNsPyTorch autogradGPU basics
    • Karpathy: Neural Networks, Zero to Hero video + code
    • fast.ai: Practical Deep Learning course
    • Dive into Deep Learning free book
    • PyTorch Tutorials docs

  4. L3~4 weeks

    Tokens, embeddings and attention

    The transformer is the engine inside every modern LLM. Once you've written self-attention yourself, papers and release notes stop being magic.

    tokenization (BPE)embeddingsself-attention · Q/K/Vmulti-headpositional encoding · RoPEdecoder-only GPT
    • Attention Is All You Need paper, 2017
    • Jay Alammar: The Illustrated Transformer article
    • Karpathy: Let's build GPT from scratch video
    • 3Blue1Brown: Neural Networks (transformer chapters) video

  5. L4~4 weeks

    How LLMs are trained, served and run locally

    Pretraining gives knowledge; fine-tuning and RLHF give behavior. On the serving side, quantization and the KV cache decide whether a model fits on your GPU. Rule of thumb: a 4-bit GGUF needs about 0.6 GB of memory per billion parameters, plus room for context.

    pretraining · scaling lawsSFT · RLHF · DPOsampling · temperaturecontext windowKV cachequantization (Q4, GGUF)LoRAprompting

    • Karpathy: Intro to Large Language Models video
    • Scaling Laws for Neural Language Models paper
    • Anthropic prompt engineering guide docs
    • Ollama and llama.cpp local runtimes

  6. L5~4 weeks

    Building LLM applications

    Real products combine a model with your data (RAG), structured outputs, tool calls and, most importantly, evaluations. Without an eval set you can't tell whether a change helped.

    embeddings · vector searchchunking · rerankingRAGtool use · JSON schemaevals · LLM-as-judgelatency & costprompt caching

  7. L6~4 weeks

    Agents, protocols and guardrails

    An agent is a model in a loop that chooses tools until a goal is met. MCP standardizes how tools plug in; A2A how agents talk to each other. The hard part is containment: least-privilege tools, sandboxes, approvals and defenses against prompt injection.

Learn by poking at it

Playground

Two toy mechanisms you can drag around with your mouse. Neither is a trained model: the gradient descent demo optimizes a real function, and the attention demo runs the real Q·K softmax math on embeddings generated from a word hash rather than learned weights. Enough to build intuition for L0 and L3.

Gradient descent on a double well

f(x) = x⁴⁄4 − x². Click the curve to place the ball, or drag the start slider, then step through gradient descent. Too high a learning rate overshoots the minimum; starting on the wrong side finds the other one.

Self-attention weights

Type a short sentence. Each word becomes an 8-dimensional vector from a deterministic hash, and the grid shows softmax(QKᵀ/√d) — the formula from Attention Is All You Need, just without training. Darker cells mean a word attends more to that column.
